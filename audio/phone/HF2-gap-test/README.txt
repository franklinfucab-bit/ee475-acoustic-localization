EE475 GAP TEST — 18–22 kHz BURST, 43 ms SILENCE (2026-11-03)

Update-and-Start opens the PC menu on this gap test. Play this file unless the menu is changed to 20 kHz.

01_LOCATE_18-22kHz_43ms-gap.wav
01_LOCATE_18-22kHz_43ms-gap.mp3
  Right channel only, 48 kHz. Each 85.333 ms period is a 43 ms coded burst
  followed by 43 ms of silence. The occupied band is 18–22 kHz.
  On the computer, select "Gap test | 18-22 kHz", then Start Scan.
  Loop this file on the phone. Prefer the WAV when the player can use it.

18 kHz can be audible. Keep the same volume and phone position used for the
19–21 kHz beacon when comparing them. Do not replace 01_LOCATE_20kHz.

The capture length is still 4096 samples. Samples between USB packets are not
joined, so this test does not use a longer period than one capture.
