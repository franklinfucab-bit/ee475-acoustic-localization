# 队友交接说明 — 2026-11-02

这部分负责 Tagalong 跟踪机器人的 **SEN0325 麦克风阵列、Pico 采集、电脑声音定位和手机播放**。当前电脑端是 RX4，Pico 固件是 v0.6-RX2，手机端是 Beacon Loop 1.1。

## 先从哪里看

根目录 README 有接线和启动方法；SETUP_WINDOWS.md 说明换电脑怎么配环境；INTEGRATION.md 写了数据格式和接口边界；FILE_CATALOG.md 列出共享文件及用途。让 AI 接手时，先给它 AI_HANDOFF.md 和根目录 AGENTS.md。

## 我们已经做了什么

- Pico 同步采集 7 路麦克风，通过带 CRC 检查的 USB 数据包传给电脑。
- 电脑识别指定的 19–21 kHz 编码信标，显示方向、收到的波形和频谱。电脑不播放定位音。
- RX4 在原有估计失败时增加联合时延拟合，让同一段录音多产生一些可接受的结果。没有按转向幅度封锁角度。
- Android 本地播放器已生成 APK。可以导入文件、播放/暂停并循环播放，也有内置定位音。手机实机、熄屏和后台播放还需要验收。
- 测试结果已有带图报告，历史资料已放进 legacy，当前源码保持原来的工程目录。

## 还没做完什么

目前仍会出现方向不稳定，特别是高频、远距离和反射较强时。29 日录音重放中，RX3 有 52 次接受结果，RX4 有 81 次；这不能解释成准确率。该次测试有多轮播放和人为暂停，不能把所有没有箭头的时间都算成 bug。

显示的雷达圆环不是距离。我们还没有完整的已知角度标注，也没有把结果传给 ESP32 控制电机。前方距离传感器、避障和跟随控制由整车部分继续集成。

## 队友怎么先跑起来

按 README 的 GPIO 表检查接线，插入 Pico，启动电脑程序后点 Start Scan。手机安装 android-player/releases/BeaconLoop-1.1.apk。19-21 kHz beacon 和 Gap test 18-22 kHz 要与电脑菜单一致。距离约 0.5 m，位置与音量保持固定。先看频谱有没有对应频段能量，再看方向。记录真实角度和主动暂停的时刻，避免后面看日志时混淆。

导入自定义音频时，手机和电脑必须使用匹配的同一个信标。手机能播放的文件比定位器能识别的范围大；当前定位器要求 48 kHz 下每 4096 个采样重复的宽带编码，任意音乐或警报声不能直接当定位信标。

归一化默认关闭。它只是保守调整播放增益，不会自动校准阵列，也没有证明能延长距离。不要为了让箭头连续，就加上“转角大于某个值直接丢弃”的限制。
